# How EPO plans work
scope: EPO

## EPO network rules
An EPO (exclusive provider organization) plan covers care only from providers in its network, like an HMO, but you usually do not need a primary care provider or referrals.

## Out-of-network care on an EPO
An EPO does not cover out-of-network care except emergencies. If you choose an out-of-network clinic for non-emergency care, including an out-of-network urgent care clinic, you are responsible for the whole bill.

## Specialists on an EPO
You can see an in-network specialist without a referral. Check that the specialist is in the EPO network first, because out-of-network specialist visits are not covered.
